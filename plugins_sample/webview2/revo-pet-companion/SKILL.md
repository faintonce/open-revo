# 机甲灵动智宠 (Revo Pet Companion)

OpenRevo 桌面悬浮机甲智宠，是基于 Rust 硬件微内核与 LLM 脑神经中枢之上的桌面伴侣形态插件。

## 核心特性
1. **纯透明悬浮窗口**：尺寸 300x320，背景 100% 透明，无系统边框，任意拖拽摆放。
2. **全局快捷键随时唤醒 (`Ctrl + Shift + V`)**：
   - 无论处于全屏游戏还是码字，按键即可唤醒智宠对讲。
3. **真实声纹律动**：
   - 麦克风音频分析（Web Audio API），光环随音量大小实时起伏。
4. **微软原生高保真 TTS 朗读**：
   - 自动绑定系统内置的微软中文神经语音（惠惠/瑶瑶/康康），零延迟流式朗读。
5. **硬件自然语言调控闭环**：
   - 支持自然语言下达指令（“有点烫吹吹风”、“打黑神话拉满性能”、“在图书馆安静点”），直接闭环触发硬件动作并在气泡中展示动作卡片。
