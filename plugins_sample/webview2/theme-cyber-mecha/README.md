# Cyber Mecha 经典机甲霓虹皮肤 (Plugin Skin)

这是 OpenRevo 官方经典机甲赛博朋克风皮肤插件（提取自旧版内置 Cyber 风格）。

## 皮肤特性
* **经典机甲配色**：保留天蓝、翠绿、玫瑰红、高能金等多色硬件语义指示。
* **微光轮廓与氛围**：为模式切换卡片、风扇与各硬件卡片赋予经典的微光边缘与霓虹高亮。
* **全平台兼容**：支持在 WebView2 界面与原生 Slint 界面（通过 ThemeTokenParser）中消费与加载。

## 使用方法
将此目录放置在 `%APPDATA%\OpenRevo\plugins\` 目录下，在控制台的“插件与皮肤”面板中一键启用即可生效。
