# OpenRevo 笔记本硬件控制能力指南 (OpenRevo Hardware Skill)

本指南面向大语言模型（LLM）与外部 AI Agent。当大模型接入 OpenRevo 微内核平台时，可以通过 Function Calling 直接下发以下硬件指令或按场景组合执行。

---

## 1. 基础硬件原子能力 (Atomic Tools)

### 1.1 `get_system_telemetry` - 硬件状态快照感知
* **描述**：在执行策略调整前或回答用户系统健康咨询时，调用此工具获取当前电源模式、强冷状态、电池上限与外设开关。
* **参数**：无

### 1.2 `set_fan_boost` - 一键全速强冷 (Fan Boost)
* **描述**：开启或关闭双风扇全速暴走排气（5400+ RPM），瞬间强化散热。
* **参数**：
  * `enable` (`boolean`, 必填): `true` 为开启强冷，`false` 为恢复智能温控。

### 1.3 `set_power_mode` - 性能功耗模式切换
* **描述**：切换整机 CPU/GPU 功耗偏置与功耗墙（PL1/PL2）。
* **参数**：
  * `mode` (`integer`, 必填):
    * `1`: **办公模式 (Office)** - 低功耗、静音、离电续航
    * `2`: **均衡模式 (Balance)** - 兼顾流畅与静音日常使用
    * `3`: **狂暴模式 (Turbo/Beast)** - 游戏电竞、3D 渲染，解锁全部硬件功耗
    * `4`: **自定义模式 (Custom)** - 高级玩家自定义功耗与风扇曲线

### 1.4 `switch_refresh_rate` - 显示屏刷新率瞬切
* **描述**：调用 Win32 底层显示配置无黑屏快速切换屏幕刷新率。
* **参数**：
  * `hz` (`integer`, 必填): 目标刷新率，如 `60`, `165`, `240`。

### 1.5 `set_battery_limit` - 电池健康养护充电上限
* **描述**：设置电池养护模式。达到上限后硬件直供断充，防止电池长期满电高压鼓包。
* **参数**：
  * `limit` (`integer`, 必填): `60` (长时间插电工作站极度养护), `80` (日常通勤推荐平衡), `100` (充满远行)。

### 1.6 `set_device_switch` - 外设硬件软开关
* **描述**：控制外设硬件通断。
* **参数**：
  * `device` (`string`, 必填): `"camera"` (摄像头), `"mic"` (麦克风), `"touchpad"` (触控板), `"winlock"` (Windows键锁定)。
  * `enabled` (`boolean`, 必填): `true` 开启, `false` 禁用。

## 2. 经典高阶组合场景模式 (Macro Scenarios)

当用户表达宏观意图时，大模型应连续调用多个工具组合完成配置：

### 2.1 游戏开黑 / 狂暴电竞模式 ("我要玩黑神话/打游戏了")
* **动作组合**：
  1. `set_power_mode({ mode: 3 })`（狂暴模式释放全部性能）
  2. `switch_refresh_rate({ hz: 240 })`（切至最高电竞刷新率）
  3. `set_device_switch({ device: "winlock", enabled: true })`（锁定 Win 键防误触）
* **桌宠回答建议**：“机甲已进入狂暴战斗姿态！功耗墙已拉满，240Hz 电竞高刷与 Win 键锁定已就绪，祝你乱杀！”

### 2.2 图书馆 / 极静续航模式 ("我在图书馆/开会，安静省电一点")
* **动作组合**：
  1. `set_power_mode({ mode: 1 })`（办公静音模式）
  2. `set_fan_boost({ enable: false })`（确保强冷关闭，风扇停转或微转）
  3. `switch_refresh_rate({ hz: 60 })`（屏幕降至 60Hz 显著延长电池续航）
* **桌宠回答建议**：“已开启图书馆极静模式。风扇已压低至静音，屏幕刷新率已调至 60Hz 护航电池续航~”

### 2.3 急速物理降温 ("电脑太烫了/煎鸡蛋了")
* **动作组合**：
  1. `set_fan_boost({ enable: true })`（全速强冷启动）
  2. `set_power_mode({ mode: 2 })`（若此前处于狂暴模式，退回均衡模式降温）
* **桌宠回答建议**：“全速强冷暴走排气已启动！风扇转速已拉满，正在全力压制核心热量！”

### 2.4 插电长效办公养护 ("长插充电器办公")
* **动作组合**：
  1. `set_battery_limit({ limit: 80 })`（充至 80% 硬件自动断充）
* **桌宠回答建议**：“已为你锁定 80% 电池养护限额，电芯免受持续高压充蚀，放心长插电工作吧。”

## 3. 通信与交互协议规范
* 在 OpenRevo 全域总线中，大模型每产生一次 `tool_calls`，微内核都会触发 `llm:action:executing` 广播，桌宠小人或界面会伴随发光和动作反馈。
* 模型在调用完硬件工具后，应当用**带有桌宠机甲特色、温暖或干练的语气**给出确认汇报。
