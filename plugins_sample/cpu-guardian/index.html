🔒 底层拦截原因：Intel 原厂机制规定，当 Windows 开启了 基于虚拟化的安全性 (VBS / 核心隔离) 时，若 BIOS 未开启 Undervolt Protection (UVP)，系统将完全封锁 CPU 调压通道。
🔓 推荐解除锁定步骤：
1. 在 Windows 开始菜单搜索并打开【核心隔离】；
2. 将【内存完整性】关闭（或以管理员运行 bcdedit /set hypervisorlaunchtype off）后重启电脑；
3. 重启后即可完全解锁 MSR 调压控制权（同时消除虚拟机开销，通常可额外提升约 3%~5% 游戏性能）。
