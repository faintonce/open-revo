## 1. 配置文件位置与打开方式

### 快捷方式（推荐）
打开 OpenRevo 完整模式界面：
1. 点击顶部导航栏的 **「系统」** Tab；
2. 找到 **「配置参数 (models.json)」** 这一行；
3. 点击 **【编辑】** 按钮，系统将自动使用 Windows 记事本打开当前生效的配置文件。

### 本地物理路径
配置文件存储在当前 Windows 用户数据目录下：
```text
%APPDATA%\OpenRevo\models.json
```
*(可直接在 Windows 资源管理器地址栏输入并回车)*

## 2. 核心概念：双层规格体系

在 `models.json` 中，每台机器都包含两套并存的规格定义：

```json
{
  "mine": true,
  "model_id": "GM6IX9B",
  "display_name": "yaoshi16 Super Series GM6IX9B",
  "alias": "我的小耀世",

  /* 1. 出厂硬件真理层（只读参考 / 兜底基准） */
  "factory_specs": {
    "office":   { "pl1": 45,  "pl2": 45,  "pl4": 125, "temp_offset": 15 },
    "balanced": { "pl1": 75,  "pl2": 75,  "pl4": 125, "temp_offset": 5  },
    "turbo":    { "pl1": 205, "pl2": 205, "pl4": 200, "temp_offset": 5  },
    "base_tgp": 150,
    "max_db": 25
  },

  /* 2. 运行生效策略层（用户可自由定制） */
  "presets": {
    "office":   { "pl1": 45,  "pl2": 45,  "pl4": 125, "temp_offset": 15 },
    "balanced": { "pl1": 75,  "pl2": 75,  "pl4": 125, "temp_offset": 5  },
    "turbo":    { "pl1": 140, "pl2": 150, "pl4": 180, "temp_offset": 10 }
  }
}
```

* **`factory_specs`（出厂硬件基准）**：
  由 OpenRevo 底层驱动在开机时直接从主板 EC 芯片硬编码出厂表中读取的真理值。**请不要随意修改它**，它为你提供了一面“原厂镜子”，改崩或调乱时随时能看到出厂默认值。
* **`presets`（用户运行生效配置）**：
  **这是你真正定制策略的地方！** 当你在软件界面切换或机身按键切换「办公 / 平衡 / 狂暴」模式时，OpenRevo 会读取此处的数值，直接写入主板 EC 寄存器执行。

## 3. 字段命名与语义解析

> [!IMPORTANT]
> **严防混淆 `display_name` 与 `alias`：**
> * **`display_name`**：系统与 DMI / 注册表识别出的机器**物理硬件全称**（如 `yaoshi16 Super Series GM6IX9B`），用于匹配底层硬件通路，不要手工改动。
> * **`alias`**：**用户个性化昵称**（如 `🎮耀妹16熟了，就喊你来🚀`）。你可以自由改成任何喜欢的名字，迷你抽屉下方会显示它。

* **`mine: true`**：表示该机型是当前本机正在使用的配置（OpenRevo 保证本机预设始终排在数组第 0 位）。

## 4. 三大模式参数详解与调节建议

在 `presets` 中，每个模式（`office` / `balanced` / `turbo`）均有四个关键参数：

| 字段 | 含义与说明 | 常见范围 | 调优建议 |
| :--- | :--- | :---: | :--- |
| **`pl1`** | **持续长时功耗限制 (Watts)**<br>CPU 稳定烤机或长时间高负载运行时的最大功耗。 | 15W ~ 220W | • 办公模式建议 35W~45W（安静低功耗）<br>• 平衡模式建议 65W~75W（兼顾性能与风噪）<br>• 狂暴模式按需设定（激进可设 175W~205W，清凉可设 120W~140W） |
| **`pl2`** | **短时爆发功耗限制 (Watts)**<br>CPU 瞬时高负载（如解压缩、打开大型软件）时的瞬时功率。 | 15W ~ 250W | 通常设为与 `pl1` 相同，或略高于 `pl1`（高出 10W~30W）。 |
| **`pl4`** | **瞬时峰值硬件保护线 (Watts)**<br>防止电流骤增触发主板断电保护的绝对天花板。 | 60W ~ 250W | 建议保持出厂推荐值（办公 100~125W，平衡 125W，狂暴 200W）。 |
| **`temp_offset`** | **温控墙下调偏移量 (°C)**<br>以 100°C 结温为基准的下调度数。<br>• 偏移量 5 = 100 - 5 = **95°C 触发降频**<br>• 偏移量 15 = 100 - 15 = **85°C 触发降频** | 0 ~ 30 | • 如果觉得笔记本烫手，可加大偏移量（例如 10~15，让机器更早进入温控）<br>• 跑分或极致性能建议 5（即 95°C 墙）。 |

## 5. 实战定制案例

### 案例 A：极致静音与移动续航型 (针对移动办公)
希望在拔掉电源或深夜办公时风扇完全不转、机器冰凉：
```json
"office": {
  "pl1": 28,
  "pl2": 35,
  "pl4": 65,
  "temp_offset": 20
}
```
*(温控目标 80°C，长时功耗锁定 28W，风扇极低转速甚至停转)*

### 案例 B：克制高能效比型 (针对 3A 游戏与夏天)
夏天打游戏不想让风扇起飞（4400 RPM），同时想压低 CPU 积热、把更多供电和散热留给显卡：
```json
"turbo": {
  "pl1": 125,
  "pl2": 135,
  "pl4": 180,
  "temp_offset": 10
}
```
*(从出厂激进的 205W 降至甜品能效比的 125W，CPU 温度骤降 10~15°C，游戏帧率几乎不受影响)*

## 6. 生效机制与验证方法

1. **如何生效？**
   * 在记事本中修改数值后，按键盘快捷键 **`Ctrl + S`** 保存文件。
   * **无需重启软件**：在 OpenRevo 界面上切一下其他模式再切回来（或者直接点击当前模式），新功耗参数会立刻下发给硬件 EC 寄存器！
2. **如何验证是否真正生效？**
   * 查看主面板右上方的 **「预设目标」** 标签：数值会即时刷新为你设定的 `PL1` 与 `TGP`。
   * 使用 Cinebench 跑分或 AIDA64 单烤 FPU，观察 CPU 功耗曲线是否稳定死锁在你设定的 `PL1` 数值上。

## 7. 避坑指南与故障恢复 (FAQ)

### Q1：我改完之后 OpenRevo 报错说 JSON 解析失败？
* **原因**：JSON 格式非常严格。请检查：
  1. 是否漏掉了英文逗号 `,`，或者在最后一个字段多加了逗号；
  2. 是否误用了中文全角标点符号（如 `，`、`“`、`”`）；
  3. 括号 `{ }` 是否成对闭合。

### Q2：我改乱了，想恢复出厂设置怎么办？
* **方法 1（局部恢复）**：直接参考本文件中上方的 `factory_specs`，把里面对应的数字重新抄回 `presets` 并保存。
* **方法 2（全量恢复）**：直接把 `presets` 这一整段删掉，或者把 `%APPDATA%\OpenRevo\models.json` 删除。再次启动 OpenRevo 时，程序会自动用硬件探测的基准重新生成全新的正确配置。

### Q3：我想把调试好的配置分享给其他相同模具的机友？
* 在「系统」Tab 点击 **【导出】** 按钮，系统会弹出原生文件保存对话框，将你的配置文件导出为 `.json`。
* 对方只需要在相同位置点击 **【导入】**，即可一键享受你的调优神仙配置！
